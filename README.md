# Cargo.Ops

Protótipo local de um sistema de Compras e Supply Chain com login por perfil, dashboard, compras, importação, estoque, financeiro, agenda, chamados, relatórios, administração, cotação USD/BRL e integração Excel.

O Dashboard inclui indicadores numéricos e gráficos circulares vivos para estoque, aprovações, RFQs e chamados.

## Como abrir

Abra `web/index.html` no navegador.

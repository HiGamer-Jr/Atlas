## Resumo

O Atlas será uma Control Tower de Supply Chain para centralizar Compras, Estoque, Importação, Financeiro, Agenda, Relatórios e Administração.

Arquitetura atual:

- Frontend React + TypeScript + Vite.
- Backend FastAPI.
- Banco alvo PostgreSQL.
- Monólito Modular.
